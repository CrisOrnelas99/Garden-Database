# Garden Database Relational Schema and Data Dictionary

This document describes the implemented PostgreSQL schema. `PK` means primary key, `FK` means foreign key, and `UQ` means unique constraint. `NULL` means the column is optional. Serial identifiers are generated by PostgreSQL.

## Relational Schema

**location**(`location_id` PK, `location_name` UQ, contact, email, is_hlc, garden_status, garden_condition, bed_count, notes)

**location_group**(`location_group_id` PK, `location_group_name` UQ)

**group_location**(`location_group_name`, `location_name`), PK(`location_group_name`, `location_name`), FK(`location_group_name`) -> location_group(`location_group_name`), FK(`location_name`) -> location(`location_name`)

**budget**(`budget_id` PK, `budget_name` UQ, budget_amount, remaining_budget, notes)

**item**(`item_id` PK, `item_name` UQ, category, vendor_name, link, unit_cost, notes)

**inventory_list**(`inventory_id` PK, `item_name` UQ, FK(`item_name`) -> item(`item_name`), cumulative_asset, instock_total, reorder_point, counted, storage_location, notes)

**purchase_request**(`request_id` PK, request_date, requested_by, requesting_school, requesting_school_group, item_name, unit_cost_at_request, quantity_requested, total_cost, delivered_to_fns, review_status, ordered, budget_name, funding_source, school_year, notes); FK(`requesting_school`) -> location(`location_name`), FK(`requesting_school_group`) -> location_group(`location_group_name`), FK(`item_name`) -> item(`item_name`), FK(`budget_name`) -> budget(`budget_name`)

**inventory_transaction**(`transaction_id` PK, transaction_date, status, taken_by, for_school, for_school_group, item_name, quantity, notes); FK(`for_school`) -> location(`location_name`), FK(`for_school_group`) -> location_group(`location_group_name`), FK(`item_name`) -> inventory_list(`item_name`)

**garden_bed**(`bed_id` PK, location_name, bed_name, bed_type, bed_size_sq_ft, lifecycle_status, condition, is_full, notes); FK(`location_name`) -> location(`location_name`), UQ(`location_name`, `bed_name`)

**irrigation_setup**(`irrigation_id` PK, location_name, irrigation_name, irrigation_type, lifecycle_status, condition, notes); FK(`location_name`) -> location(`location_name`)

**compost_unit**(`compost_unit_id` PK, location_name, unit_name, compost_type, lifecycle_status, condition, notes); FK(`location_name`) -> location(`location_name`)

**plant**(`plant_id` PK, `plant_name` UQ, plant_type, growing_period, days_to_harvest, notes)

**crop_rotation**(`rotation_id` PK, status, location_name, bed_name, plant_name, quantity, season, sow_date, soil_health, notes); FK(`location_name`) -> location(`location_name`), FK(`location_name`, `bed_name`) -> garden_bed(`location_name`, `bed_name`), FK(`plant_name`) -> plant(`plant_name`)

## Data Dictionary

### location

Stores schools and program locations. Garden fields can be left empty when garden details are not tracked.

| Attribute | PostgreSQL type | Constraints and business meaning |
|---|---|---|
| location_id | SERIAL | PK; generated identifier |
| location_name | VARCHAR(200) | NOT NULL, UQ; readable location name referenced by related tables |
| contact | VARCHAR(100) | NULL; contact person |
| email | VARCHAR(200) | NULL; contact email |
| is_hlc | BOOLEAN | NOT NULL, DEFAULT FALSE; controls membership in the built-in All HLC Gardens group |
| garden_status | lifecycle_status | NULL; garden lifecycle status |
| garden_condition | condition | NULL; garden condition |
| bed_count | nonnegative_count | NULL; maintained from garden_bed rows; NULL denotes untracked garden details |
| notes | TEXT | NULL; additional location or garden details |

CHECK: garden_status, garden_condition, and bed_count must all be NULL, or bed_count and garden_status must be non-NULL. Locations with related beds, irrigation setups, or compost units cannot be deleted.

### location_group

Stores named groups of locations.

| Attribute | PostgreSQL type | Constraints and business meaning |
|---|---|---|
| location_group_id | SERIAL | PK; generated identifier |
| location_group_name | VARCHAR(200) | NOT NULL, UQ; readable group name |

### group_location

Associative relation connecting locations to groups; one row per group membership.

| Attribute | PostgreSQL type | Constraints and business meaning |
|---|---|---|
| location_group_name | VARCHAR(200) | NOT NULL; composite PK; FK to location_group.location_group_name; update/delete cascades |
| location_name | VARCHAR(200) | NOT NULL; composite PK; FK to location.location_name; update/delete cascades |

The built-in All HLC Gardens group is maintained from location.is_hlc. Its membership must not be manually changed. Referenced groups must have at least one location; the database prevents removing the last member while a request or transaction references the group. Custom groups are managed through this table.

### budget

Stores budget amounts and the calculated remaining balance.

| Attribute | PostgreSQL type | Constraints and business meaning |
|---|---|---|
| budget_id | SERIAL | PK; generated identifier |
| budget_name | VARCHAR(100) | NOT NULL, UQ; referenced by purchase requests |
| budget_amount | dollar | NOT NULL; nonnegative total amount |
| remaining_budget | dollar | NULL; recalculated from ordered requests |
| notes | TEXT | NULL; additional details |

### item

Catalog of supplies that may be purchased or tracked in inventory.

| Attribute | PostgreSQL type | Constraints and business meaning |
|---|---|---|
| item_id | SERIAL | PK; generated identifier |
| item_name | VARCHAR(200) | NOT NULL, UQ; referenced by requests and inventory |
| category | VARCHAR(50) | NULL; item category |
| vendor_name | VARCHAR(50) | NULL; supplier |
| link | TEXT | NULL; product or supplier URL |
| unit_cost | dollar | NULL; nonnegative catalog unit cost |
| notes | TEXT | NULL; additional details |

### inventory_list

Tracks current stock. A catalog item can have at most one inventory row.

| Attribute | PostgreSQL type | Constraints and business meaning |
|---|---|---|
| inventory_id | SERIAL | PK; generated identifier |
| item_name | VARCHAR(200) | NOT NULL, UQ; FK to item.item_name; referenced item name is restricted from update |
| cumulative_asset | nonnegative_count | NOT NULL, DEFAULT 0; total acquired quantity |
| instock_total | nonnegative_count | NOT NULL, DEFAULT 0; available quantity after stock movements |
| reorder_point | nonnegative_count | NULL; threshold used by RestockList |
| counted | BOOLEAN | NOT NULL, DEFAULT FALSE; whether stock was physically counted |
| storage_location | VARCHAR(200) | NULL; storage location |
| notes | TEXT | NULL; additional details |

### purchase_request

Records requested items, request status, delivery, and optional budget and funding details.

| Attribute | PostgreSQL type | Constraints and business meaning |
|---|---|---|
| request_id | SERIAL | PK; generated identifier |
| request_date | DATE | NULL; date requested |
| requested_by | VARCHAR(50) | NOT NULL; requester name |
| requesting_school | VARCHAR(200) | NULL; FK to location.location_name; single-location assignment |
| requesting_school_group | VARCHAR(200) | NULL; FK to location_group.location_group_name; group assignment |
| item_name | VARCHAR(200) | NOT NULL; FK to item.item_name; referenced item name is restricted from update |
| unit_cost_at_request | dollar | NULL; unit price snapshot, populated from catalog when omitted if available |
| quantity_requested | nonnegative_count | NULL in column definition; CHECK > 0 when supplied |
| total_cost | dollar | NOT NULL, DEFAULT 0; calculated from quantity and price snapshot; explicitly supplied historical totals may be retained |
| delivered_to_fns | BOOLEAN | NOT NULL, DEFAULT FALSE; delivery state |
| review_status | TEXT | NULL; review or order status |
| ordered | BOOLEAN | NOT NULL, DEFAULT FALSE; order state |
| budget_name | VARCHAR(100) | NULL; FK to budget.budget_name; update cascades |
| funding_source | VARCHAR(100) | NULL; funding source text |
| school_year | VARCHAR(9) | NULL; associated school year |
| notes | TEXT | NULL; additional request details |

CHECK: requesting_school and requesting_school_group cannot both be non-NULL. When one is entered, a trigger clears the other. Both may be NULL for a personal/unassigned request. A request marked delivered must have a quantity. Referenced groups must have members. Ordered requests update remaining budget; delivered requests may update inventory.

### inventory_transaction

Records inventory check-ins and check-outs.

| Attribute | PostgreSQL type | Constraints and business meaning |
|---|---|---|
| transaction_id | SERIAL | PK; generated identifier |
| transaction_date | DATE | NULL, DEFAULT CURRENT_DATE; transaction date |
| status | inventory_transaction_status | NOT NULL; Checked In or Checked Out |
| taken_by | VARCHAR(50) | NOT NULL; person handling transaction |
| for_school | VARCHAR(200) | NULL; FK to location.location_name; single-location assignment |
| for_school_group | VARCHAR(200) | NULL; FK to location_group.location_group_name; group assignment |
| item_name | VARCHAR(200) | NOT NULL; FK to inventory_list.item_name; referenced item name is restricted from update |
| quantity | nonnegative_count | NOT NULL; CHECK > 0 |
| notes | TEXT | NULL; additional details |

CHECK: for_school and for_school_group cannot both be non-NULL. A trigger clears the other when one is entered. Both may be NULL for personal use. Transactions change available inventory; check-outs cannot reduce stock below zero. Referenced groups must have members.

### garden_bed

Stores beds associated with a location's garden.

| Attribute | PostgreSQL type | Constraints and business meaning |
|---|---|---|
| bed_id | SERIAL | PK; generated identifier |
| location_name | VARCHAR(200) | NOT NULL; FK to location.location_name; deletion restricted |
| bed_name | VARCHAR(100) | NOT NULL; unique within its location |
| bed_type | VARCHAR(50) | NULL; bed type |
| bed_size_sq_ft | DECIMAL(10,2) | NULL; CHECK nonnegative when supplied |
| lifecycle_status | lifecycle_status | NULL; Active, Planned, or Inactive |
| condition | condition | NULL; Good, Require Maintenance, or In Maintenance |
| is_full | BOOLEAN | NOT NULL, DEFAULT FALSE; whether the bed is full |
| notes | TEXT | NULL; additional details |

UNIQUE(location_name, bed_name). A bed requires a location with garden details and cannot be deleted while crop rotations reference it. location.bed_count is maintained from bed rows.

### irrigation_setup

Stores irrigation systems by location.

| Attribute | PostgreSQL type | Constraints and business meaning |
|---|---|---|
| irrigation_id | SERIAL | PK; generated identifier |
| location_name | VARCHAR(200) | NOT NULL; FK to location.location_name; deletion restricted |
| irrigation_name | VARCHAR(100) | NOT NULL; must not be blank; unique per location without regard to case or surrounding whitespace |
| irrigation_type | VARCHAR(100) | NULL; irrigation type |
| lifecycle_status | lifecycle_status | NULL; Active, Planned, or Inactive |
| condition | condition | NULL; Good, Require Maintenance, or In Maintenance |
| notes | TEXT | NULL; additional details |

An irrigation setup requires a location with garden details.

### compost_unit

Stores compost units by location.

| Attribute | PostgreSQL type | Constraints and business meaning |
|---|---|---|
| compost_unit_id | SERIAL | PK; generated identifier |
| location_name | VARCHAR(200) | NOT NULL; FK to location.location_name; deletion restricted |
| unit_name | VARCHAR(100) | NOT NULL; must not be blank; unique per location without regard to case or surrounding whitespace |
| compost_type | VARCHAR(100) | NULL; compost unit type |
| lifecycle_status | lifecycle_status | NULL; Active, Planned, or Inactive |
| condition | condition | NULL; Good, Require Maintenance, or In Maintenance |
| notes | TEXT | NULL; additional details |

A compost unit requires a location with garden details.

### plant

Catalog of plants; planting-specific information is stored in crop_rotation.

| Attribute | PostgreSQL type | Constraints and business meaning |
|---|---|---|
| plant_id | SERIAL | PK; generated identifier |
| plant_name | VARCHAR(100) | NOT NULL, UQ; referenced by crop rotations |
| plant_type | VARCHAR(50) | NULL; plant type |
| growing_period | VARCHAR(100) | NULL; general growing period |
| days_to_harvest | nonnegative_count | NULL; must be greater than zero when supplied |
| notes | TEXT | NULL; additional details |

### crop_rotation

Tracks plantings planned or grown in garden beds.

| Attribute | PostgreSQL type | Constraints and business meaning |
|---|---|---|
| rotation_id | SERIAL | PK; generated identifier |
| status | rotation_status | NULL, DEFAULT Planned; Planned, In-ground, Removed, or Harvested |
| location_name | VARCHAR(200) | NOT NULL; FK to location.location_name and part of composite FK to garden_bed |
| bed_name | VARCHAR(100) | NOT NULL; part of composite FK to garden_bed(location_name, bed_name) |
| plant_name | VARCHAR(100) | NOT NULL; FK to plant.plant_name; update cascades |
| quantity | nonnegative_count | NULL in column definition; CHECK > 0 when supplied |
| season | VARCHAR(20) | NULL; growing season |
| sow_date | DATE | NULL; sowing date |
| soil_health | soil_health_status | NULL; Good, Fair, or Needs Replacement; cleared when status becomes Removed |
| notes | TEXT | NULL; additional planting details |

The referenced location must have garden details. The referenced bed must belong to that location and be Active or Planned when a rotation is inserted or its bed assignment changes. A rotation's bed cannot be deleted while referenced.
